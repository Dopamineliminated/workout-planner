# 💪 헬스 루틴 플래너

내 정보와 목표를 입력하면 **요일별 맞춤 웨이트 루틴**을 만들어 주고, 실제 수행 기록을 남기면 **미달·초과 정도에 따라 다음 주 목표(무게·반복)를 자동으로 조정**해 주는 웹앱입니다.

**🔗 바로 사용:** https://dopamineliminated.github.io/workout-planner/

- 서버·설치 필요 없음. 브라우저만 있으면 동작하는 **정적 사이트**입니다.
- 데이터는 **각 기기 브라우저(localStorage)** 에 저장됩니다(내보내기/가져오기로 기기 간 이동).
- 내장 알고리즘이 즉시 루틴을 만들고, 원하면 **Claude API로 더 정교하게 다듬을** 수 있습니다(선택).

---

## 사용 방법

1. 위 링크에 접속(또는 폰 홈 화면에 추가).
2. **시작하기** — 프로필(경력·주당 일수·세션 시간·장비)과 목표(근비대/근력/감량·분할·집중 근육·진행 속도)를 입력 → 첫 루틴 생성. 프로그램 시작일 기본값은 **다음 주 월요일**.
3. **루틴** — 요일별 운동·세트×횟수·휴식·목표 무게 확인. `다시 생성`으로 구성 변경, `AI로 다듬기`로 재조정(키 필요).
4. **기록** — 각 세트의 실제 반복수·무게를 입력·저장.
5. **다음 주 루틴 생성** — 이번 주 기록을 분석해 다음 주 목표 자동 조정.
6. **체성분** — 인바디 측정값을 직접 입력하면 추이 그래프로 확인.

---

## 자동 조정 규칙 (이중 점진 과부하)

| 지난주 수행 | 다음 주 조정 |
|---|---|
| 모든 세트에서 목표 최대 반복 **달성** | 무게 **증량** (많이 초과 시 증량폭 2배), 반복은 하단으로 리셋 |
| 범위 내지만 최상단 미도달 | 무게 유지 → 반복수 상향 도전 |
| 절반 이상 최소 반복 **미달** | 같은 무게로 반복 숙달 |
| 최소 반복을 **크게 미달**(-3회↑) | 무게 **10% 감량** 후 재도전 |
| 기록 없음(스킵) | 목표 유지 |

증량 단위: 대근육 복합 5kg · 상체 복합 2.5kg · 고립 1.25kg. `진행 속도`로 증량폭 조절(천천히 ×0.5 / 표준 ×1 / 빠르게 ×1.5).

## Claude AI 다듬기 (선택)

`설정 → Claude AI 연동`에서 Anthropic API 키를 입력하면, 루틴 화면의 **AI로 다듬기** 버튼으로 Claude(기본 `claude-opus-4-8`)가 근육 균형·회복·볼륨을 재검토해 루틴을 개선합니다.

- 키는 **이 브라우저(localStorage)에만** 저장되며, 사용할 때만 Anthropic 서버로 직접 전송됩니다(코드·레포에는 저장되지 않음).
- 공용 PC에서는 키 입력을 피하세요.
- 키가 없거나 호출이 실패해도 내장 알고리즘 루틴은 그대로 동작합니다.

---

## 데이터 저장 · 이동

- 모든 데이터는 접속한 **기기의 브라우저**에 저장됩니다(기기 간 자동 동기화 없음).
- 다른 기기로 옮기려면 `설정 → 데이터 내보내기(JSON)` 후, 다른 기기에서 `데이터 가져오기`.
- `전체 초기화`로 모두 삭제(되돌릴 수 없음).

## 로컬에서 실행 / 개발

정적 파일이라 아무 정적 서버로도 열 수 있습니다. 저장소에 포함된 미리보기 서버:

```bash
node serve.js   # → http://localhost:5178
```

> `file://` 로 직접 열면 ES 모듈 로딩이 막히므로, 위 서버나 `npx serve` 같은 정적 서버를 쓰세요.

## 구조

```
workout-planner/
├─ index.html            # 앱 셸
├─ css/styles.css
├─ js/
│  ├─ app.js             # UI·라우팅·뷰
│  ├─ store.js           # 상태 관리 + localStorage 저장 + 로직 실행
│  ├─ engine.js          # 루틴 생성 엔진 (순수 로직)
│  ├─ adjust.js          # 다음 주 자동 조정 (이중 점진, 순수 로직)
│  ├─ exercises.js       # 운동 데이터베이스
│  ├─ templates.js       # 분할·세션·세트/횟수 스킴
│  ├─ core-util.js       # 날짜/반올림 유틸
│  ├─ ai.js              # Claude API 연동(브라우저 직접 호출, 선택)
│  └─ util.js            # DOM·차트 유틸
├─ serve.js              # 로컬 미리보기용 정적 서버(선택)
└─ package.json
```

`engine.js` · `adjust.js` · `exercises.js` · `templates.js` · `core-util.js` 는 브라우저·Node 공용 순수 모듈이라, 향후 **동적(서버/계정) 버전**으로 확장할 때 백엔드에서 그대로 재사용할 수 있습니다.

## 배포 (GitHub Pages)

## 향후 계획

정적(localStorage) 버전으로 사용해 보다가, 필요하면 서버 + 계정(로그인) + 기기 간 동기화 및 유료화까지 확장 예정. 순수 로직 모듈은 그대로 재사용합니다.
